# finledgerpoli brand assets

Source artwork for the finledgerpoli mark and marketing images. Hand-written SVG; PNGs are renders of the SVGs.

- `mark.svg`: the logo mark (squared light f on the green tile; the accent crossbar runs right like a ledger entry). `mark-16.svg` is the dedicated 16 px cut.
- `lockup-light.svg` / `lockup-dark.svg`: mark plus wordmark, for light and dark backgrounds.
- `favicon.svg`, `favicon-32.png`, `apple-touch-icon-180.png`, `icon-512.png`: browser and app icons.
- `social-dark.*`: the GitHub social preview (1280x640). `social-light.*` is the light alternate.
- `how-it-works-dark.*` / `how-it-works-light.*`: the five-step diagram for GitHub's dark and light themes.

Palette: tile `#2f7a63` to `#28634f`, accent `#8fc3ab`, soft `#e1ebe4`, ink `#212b26`, dark ground `#0e1210`. All example content in the images is fictional.
